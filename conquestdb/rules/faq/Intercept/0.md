Please ask yourself the following:
Does it target? If no, then it can't.
Does it do something expressly forbidden by the rules, e.g. sacrifice a warlord unit? If yes, then it can change the target, but nothing will happen.
Does it do something that leads to a nonsenical game-state, such as returning a warlord to your hand? If yes, it is likely that it can change the target, but nothing will happen.
Otherwise, it very likely can do it; please consider asking on Intercept's page.
